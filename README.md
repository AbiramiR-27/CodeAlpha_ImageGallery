# CodeAlpha Image Gallery

## Overview
This project is a simple image gallery web application. It allows users to view a collection of images in a visually appealing layout.

## Features
- Responsive image gallery layout
- Easy to add or remove images
- Clean and modern design

## Getting Started

### Prerequisites
- A web browser (Chrome, Firefox, Edge, etc.)

### Usage
1. Clone the repository:
   ```
   git clone https://github.com/AbiramiR-27/CodeAlpha_ImageGallery.git
   ```
2. Open `task1.html` in your web browser to view the gallery.

## Project Structure
```
CodeAlpha_ImageGallery/
  task1.html
```

## Customization
- To add more images, edit the `task1.html` file and include additional `<img>` tags in the gallery section.
